Thực hành nhúng CSS vào HTML

Phần 1: Inline Style

Đoạn văn này được đổi màu bằng CSS viết trực tiếp trong thuộc tính style của thẻ HTML.

Phần 2: Internal Style

Đoạn văn này được đổi màu bằng CSS đặt trong thẻ <style> bên trong phần <head>.

Phần 3: External Style

Đoạn văn này được đổi màu bằng CSS nằm trong file style.css và được liên kết bằng thẻ link.
