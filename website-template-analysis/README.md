# Phân tích và Xây dựng Cấu Trúc Website Template

## 1. Website được phân tích

Website tham khảo: **MDN Web Docs** - một website tài liệu học lập trình web.

## 2. Phân tích cấu trúc

### Header
Header nằm ở phần đầu trang, dùng để giới thiệu thương hiệu/tên website và nội dung mở đầu. Trong một website tài liệu như MDN, khu vực đầu trang giúp người dùng nhận biết trang và nhanh chóng định hướng nội dung.

### Navigation Menu
Thanh điều hướng chứa các liên kết đến những phần chính của website. Menu thường nằm gần phía trên trang để người dùng có thể chuyển nhanh giữa các nội dung quan trọng. Trong bài làm, menu gồm 4 mục: Trang chủ, HTML, CSS và JavaScript.

### Content Section
Đây là vùng nội dung chính của trang. Bố cục được chia thành hai khu vực: phần nội dung chính và sidebar. Nội dung chính chứa các chủ đề học tập, còn sidebar chứa thông tin phụ và hình minh họa. Kiểu bố cục này giúp nội dung chính nổi bật nhưng vẫn giữ được các liên kết hoặc thông tin hỗ trợ bên cạnh.

### Footer
Footer nằm ở cuối trang, dùng để hiển thị thông tin bản quyền và các thông tin chung của website.

## 3. Cấu trúc file

```text
website-template-analysis/
├── index.html
├── style.css
└── README.md
```

## 4. Nội dung đã triển khai

- Header có tiêu đề trang.
- Navigation Menu có 4 mục điều hướng.
- Content Section gồm phần mô tả, các khối nội dung và hình ảnh.
- Sidebar hiển thị thông tin phụ.
- Footer chứa thông tin bản quyền.
- CSS sử dụng Grid, Flexbox, khoảng cách và responsive cho màn hình nhỏ.
